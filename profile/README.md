drift-ui is an open source component registry for React 19 and Tailwind v4. It covers the components shadcn/ui leaves out, like a tags input, stepper, tree view and diff viewer, and you install them with the shadcn CLI you already use:

```bash
npx shadcn add @drift-ui/tags-input
```

Every component ships as source in your project. Pick Radix or Base UI through the `style` in your `components.json`, and the colors follow your existing shadcn theme.

### Repositories

| Repository                                   | What's in it                                                                                            |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [ui](https://github.com/drift-ui/ui)         | 52 web components, their tests, and the docs site at [drift-ui.dev](https://drift-ui.dev)               |
| [native](https://github.com/drift-ui/native) | React Native versions of the components, starting with a pilot ([ui#132](https://github.com/drift-ui/ui/issues/132)) |

### Contributing

Start with an issue labelled [good first issue](https://github.com/drift-ui/ui/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22), then read [CONTRIBUTING.md](https://github.com/drift-ui/ui/blob/main/CONTRIBUTING.md) for setup and the steps to add a component. Anyone with a merged pull request is listed on the [contributors page](https://drift-ui.dev/contributors).

Questions go to [Discord](https://discord.gg/tJH3dC8Exz) or [hello@drift-ui.dev](mailto:hello@drift-ui.dev).
